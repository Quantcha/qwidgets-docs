# AI Prompt

Ask your own AI model a question and read the answer on your workspace. It uses an AI integration, Claude or Gemini, with your own API key; see [Accounts and connections]({{ '/accounts/' | relative_url }}).

## Using it

Type in **Prompt** and select **Send**. The answer appears above, formatted. Each prompt stands alone: the model doesn't see earlier prompts or anything else on the workspace. The prompt is saved with the widget; the answer isn't.

## Settings

**Configure** sets the **Integration** and the **AI Model**, from the models your key can use.

On a shared workspace, visitors see the prompt, but can't send it: sending uses the sender's own integration.
