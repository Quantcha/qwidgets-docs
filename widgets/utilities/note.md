# Note

A note you write and format right on the workspace, and it saves as you type.

{% include shot.html id="note" alt="A note titled Trade plan with two numbered items, below a formatting toolbar." %}

## Using it

Type in the widget. The toolbar sets headings, fonts, bold, italic, underline, colors, lists, alignment, links, images, and code. The note saves a few seconds after you stop typing.

There's nothing to configure beyond the title and colors.
