# Prediction Search

Search prediction market events across every provider without leaving your workspace. It's the [search page]({{ '/prediction-markets/search/' | relative_url }}) in a widget.

{% include shot.html id="event-contract-search" alt="Prediction Event Search for fed across all providers, sorted by relevance, listing Kalshi Fed decision events with their type, tags, settlement dates, and 24-hour volume." %}

## What it shows

Up to 50 matching events. Each shows its title and subtitle, then tags for its type, competition, expected settlement, and 24-hour volume, with the provider on the right.

## Settings

The top bar holds the search: the query, a provider (**All**, or one), and the sort (**Relevance**, **Volume24h**, or **Settlement Expected At**). Changes are saved with the widget. There's nothing to configure.

## Actions

Each result's **⋮** opens the event beside the search: **Open Event Chart**, **Open Event Table**, **Open Event History**, or **Open Related Events**.
