# Related Events

Other events tied to the one you're following: the same question on other dates, or related questions.

{% include shot.html id="event-contract-related-events" alt="Series events for a Kalshi inflation event: the same question for November and December 2026." %}

## What it shows

Tiles under **Related Events** and **Series Events**, each with its title and subtitle. Kalshi and Polymarket publish these; other providers don't.

## Settings

**Configure** sets the **Provider** and **Event ID**.

## Actions

Each tile's **⋮** opens that event (**Open Event Table**, **Open Event Chart**, **Open Event History**), or **Switch to Event**, which points this widget at it instead.
